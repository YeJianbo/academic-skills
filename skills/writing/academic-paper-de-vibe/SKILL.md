# Academic Paper De-Vibe

用于把“像 AI 写的论文草稿”改成严谨、自然、可投稿的学术表达。默认面向密码学、联邦学习、隐私计算、安全与 CS 论文；不要套用医学、经济学或泛营销文本的风格。

## 执行顺序

1. 先诊断逻辑，再改语言。若论证链断裂，先指出问题，不要只做同义改写。
2. 保留真实技术主张，不编造 citation、实验结果、安全证明或定理结论。
3. 明确区分三类输出：问题诊断、修改原则、改写文本。用户只要最终文本时，可省略长诊断。
4. 对密码学/隐私计算论文，优先检查威胁模型、隐私目标、安全定义、假设、证明边界和效率评估。
5. 对联邦学习论文，优先检查 FL 设置、数据异质性、攻击模型、效用-隐私-效率权衡和实验回扣。

## 诊断清单

### 1. 动机与叙事

- 问题：背景泛泛而谈，直接跳到方法；痛点没有落到具体攻击、协议瓶颈、隐私泄露路径或 FL 系统约束。
- 修复：按“应用场景 -> 具体限制 -> 现有方法缺口 -> key insight -> 本文方案”推进。
- 要求：每段只完成一个任务，避免反复解释同一个 motivation。

### 2. 安全/隐私模型

- 问题：只说 secure、private、robust，却没有说明保护什么、保护谁、对抗谁。
- 修复：明确 adversary type、corruption/collusion、honest-but-curious 或 malicious、adaptive 能力、泄露量、信任假设和安全参数。
- 要求：攻击实验下降不能替代形式化隐私保证；经验防御和定理证明必须分开写。

### 3. 符号、公式与证明

- 问题：符号首次出现未定义；定理与方法脱节；证明像装饰；公式只是堆叠。
- 修复：统一符号，先定义对象和游戏，再给定理；长证明在正文给 proof roadmap，细节放附录。
- 要求：不要声称强于模型的安全性或隐私性。

### 4. 方法、协议与算法

- 问题：模块名夸张，协议步骤像工程堆叠，伪代码描述标准训练循环或常规优化器。
- 修复：保留能体现核心贡献的构造、协议消息、聚合规则、加密/扰动/证明步骤。
- 要求：每个组件都回答“为什么需要它”，并对应证明、复杂度分析、攻击评估或消融。

### 5. 实验与评估回扣

- 问题：只报告准确率涨跌，不解释隐私收益、通信开销、攻击效果或部署约束。
- 修复：把实验结论回扣到引言里的痛点和方法里的设计选择。
- 要求：比较必须匹配安全等级、隐私预算、攻击模型、数据划分和系统规模。

### 6. AI 写作痕迹

- 内容痕迹：过度强调意义、空泛地说 broader impact、公式化“挑战与未来展望”、没有实证或证明支撑的强结论。
- 语言痕迹：overly, significantly, crucial, elegant, robust framework, seamless, comprehensive, in the realm of 等虚浮表达。
- 结构痕迹：三点式排比、连续 bullet、每段同样节奏、not only ... but also、not X but Y 的机械对比。
- 格式痕迹：滥用粗体、破折号、分号、内联小标题和过密括号解释。

## 自然化规则

### 英文

- 用具体动词替代空泛动词：use, reduce, bound, prove, aggregate, encrypt, perturb, verify, reconstruct, infer。
- 删除装饰性副词：elegantly, notably, remarkably, significantly 只有在有数据支撑时保留。
- 减少模板连接词：不要机械使用 moreover, furthermore, therefore, however；优先让句间逻辑自然承接。
- 避免伪学术膨胀：把 "plays a crucial role in" 改成直接陈述作用。
- 保留必要 hedging：安全、隐私和统计结论必须与证明或实验范围一致。

### 中文

- 删除“具有重要意义”“提供了新思路”“有效解决了”等空泛评价，改成具体问题和具体收益。
- 避免口号式总结，如“为未来研究奠定基础”；除非明确说明剩余问题。
- 不把每句话都写成“本文首先、然后、最后”；用逻辑关系连接。
- 技术名词保持一致，不在同一段里反复换词。

## 输出方式

默认输出应简洁：

1. 若用户给出一段文本：直接给出改写版；必要时附 3-5 条关键修改说明。
2. 若用户要求审查：按“严重问题 -> 中等问题 -> 语言问题 -> 建议改写”输出。
3. 若用户给出 LaTeX：保留命令、引用、公式标签和术语，不随意改 citation key。
4. 若文本事实不足：标注“需要补充证据/定义/实验”，不要把语气改强。

Use these repositories as process inspiration only. Do not copy templates blindly; adapt to the local CS workflow.

- AI-Scientist style repositories and research-agent projects: useful for the loop of idea generation, experiment execution, and paper-style evaluation.

## Borrowed Process Ideas

1. Treat idea generation as a loop, not a one-shot answer.
2. Keep explicit artifacts: search log, paper matrix, hypothesis list, experiment report, reviewer critique.
3. Separate roles: researcher, feasibility engineer, reviewer, venue-fit evaluator.
4. Require an experiment or falsification step before finalizing an idea.
5. Keep the skill modular: literature search, gap mining, pilot experiment, review, writing handoff.

## Local Adaptation

The local workflow is stricter than generic GitHub research skills:

- Focus on computer science, especially cryptography, federated learning, privacy computing, and security.
- Require 40+ top-venue papers plus 40+ adjacent papers when the user asks for full discovery.
- Require local pilot experiments using conda/CUDA before finalizing.
- Require review integration with `review/cs-paper-reviewer`, `security-privacy-auditor`, and `evaluation-reproducibility-auditor`.

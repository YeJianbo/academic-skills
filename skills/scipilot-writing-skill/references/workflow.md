# 写作流程与边界情况

入口规则见 `../SKILL.md`。以下内容按任务需要使用。

## 信息与范围

读取文件和已有上下文，确定任务、载体、语言、处理范围与修改深度。局部文本未指定目标期刊时沿用原稿或通用学术表达；语言不变的润色不需要重新询问语言方向。只有会改变结果的真实歧义才询问，已授权修改直接推进。

## 按任务交付

- 一句或一段润色：提供改后文本，保留事实与术语；无需回译或新建日志。
- 较长或语义敏感改写：提供修改文件与简短说明；逐项日志、回译按用户需要提供。
- 用户要求批量语言检查：可运行 writing_lint.py，并保存实际报告。风格提示由上下文判断，不把专业术语当作必须替换的错误。
- 修改 LaTeX 或 DOCX 项目：核对差异，完成与修改相关的编译或实际渲染检查，保留模板和样式。

## 边界情况

- 输入已经清楚准确：保留原文，无需强行改写或额外评价。
- 疑似事实或数据错误：不擅自修正数值，指出位置与疑点；继续处理不受影响的表达。
- 需要补文献：使用 cs-literature-search 和原始来源核验，不编造引用或实验结论。
- 复杂 LaTeX 数学和自定义命令：保留命令与数学，只改授权的正文；先检查 latex_clean.py 的适用性，不让自动清理损坏源码。
- Word 输入含 Markdown：仅清理正文中的误用标记，保留原有标题、列表、公式和样式。
- 深度重写：可以调整结构和语序，事实、数值、结论与证据边界仍保持不变。
- lint 命中合理领域用语：保留术语并记录判断；无需反复改写来消除提示。真实格式错误仍应修复，不能伪造通过状态。

## 检查与协作

交付前核对原意、数值、公式、引用键、结论方向、模板和实际改动范围。只报告执行过的检查。科研图转 nature-figure；正式审稿转 review；格式和引用集成转 latex-paper-integrator。按任务选择协作，不为每次交付增加固定流程。

# Academic Hub

这是学术工作的总入口。优先从这里开始，再按任务分流。

## 分流

- `survey`：选题、检索、综述、相关工作、创新点检查
- `writing`：论文撰写、重写、润色、去 AI 味、结构优化
- `review`：自审、外审模拟、投稿前 readiness、回复审稿人、引用与论证检查
- `experiment`：代码实现、实验设计、运行、消融、作图、结果分析
- `tools`：LaTeX、引用、统计、数据处理、图表、检索、工作流辅助
- `tools/context-budget-manager`：长调研、长写作、长审稿、实验日志、多子代理和跨轮任务的 token/context 节约

## 使用规则

- 学术任务默认先走本入口
- 只在任务非常明确时，才直接进入某个一级分类
- 单篇论文需要先压成可回链证据卡时，先转 `survey`，由其决定是否调用 `paper-evidence-distiller`
- 二级资料保留在各分类目录中，按需打开，不作为系统级自动枚举入口
- 任务很长、材料很多或需要多子代理时，先用 `context-budget-manager` 压缩目标、读取范围和交接状态
